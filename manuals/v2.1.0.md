# Appliance Signal Studio — 2.1.0

## Start an analysis
Choose **Open** and select a CSV, Excel or supported simulation file. Data loads into the workspace. Time coordinates are displayed in **minutes**; sample-indexed data stays in samples. Check or uncheck channels in the Data Portal to show or hide traces. Use the master checkbox to select or deselect all. Filter by name, unit or source.

## Compare recordings
Open **Tools → Engineering → Recording controls**. Select power, machine and simulation recordings, choose a synchronization strategy and click **Align recordings**. The Comparison tab holds the comparison plots and match scorecard. Match colours represent ≥90%, 70–89%, and <70%.

## Navigate the plot
Use **Zoom X**, **Zoom Y**, **Zoom XY**, **Pan** and **Reset zoom**. Drag a rectangle in the chosen dimensions; use the wheel to zoom. Each unit has an independent Y-axis. Use channel appearance options to adjust colour, scale and axis assignment. Hide side panels through View to give plots more room.

## Cursors and measurements
Cursor **A is cyan**, **B is amber**. Drag either cursor; Snap follows real samples. The Readout panel shows each visible channel's A and B values. Select a channel to inspect its interval statistics.

## Properties, processing and reporting
Use **View → Properties** to inspect or edit name, unit, kind and limits. Unit metadata takes priority over name-based guesses. Tools offers channel appearance, playback, recorded phases, filters, formulas, engineering diagnostics, presets and optional extensions. Choose **Export Report** for PDF, Excel, CSV or PNG of the active analysis; additional SVG/HTML/Markdown exports are under Tools. **Save workspace** stores JSON and an adjacent NPZ: keep both together. **Restore** reopens the workspace.

## Changes in this version
First streamlined standalone workbench. Subsequent releases improve navigation, channel units and cursor locking.
