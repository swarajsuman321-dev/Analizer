# Appliance Signal Studio — 2.1.6

## Start an analysis
Choose **Open** and select a TDMS, CSV, Excel or supported simulation file. Data loads into the workspace. Time coordinates are displayed in **minutes**; sample-indexed data stays in samples. Check or uncheck channels in the Data Portal to show or hide traces. Use the master checkbox to select or deselect all. Filter by name, unit or source.

## Compare recordings
Open **Tools → Engineering → Recording controls**. Select power, machine and simulation recordings, choose a synchronization strategy and click **Align recordings**. Re-aligning updates existing source channels and adds new channels without duplicating them. The Comparison tab holds the comparison plots and match scorecard. Match colours represent ≥90%, 70–89%, and <70%.

## Navigate the plot
Use **Zoom X**, **Zoom Y**, **Zoom XY**, **Pan** and **Reset zoom**. Drag a rectangle in the chosen dimensions; use the wheel to zoom. Shortcuts: **Ctrl+1** X, **Ctrl+2** Y, **Ctrl+3** XY, **Ctrl+4** Pan, **Ctrl+0** Fit, **Ctrl+= / Ctrl+-** zoom, **Alt+Left / Alt+Right** history. Each unit has an independent Y-axis. Use channel appearance options to adjust colour, scale and axis assignment. Hide side panels through View to give plots more room.

## Cursors and measurements
Cursor **A is cyan**, **B is amber**. Drag either cursor; Snap follows real samples. The Readout panel shows each visible channel's A and B values. Select a channel to inspect its interval statistics. **Lock cursors… (Ctrl+L)** attaches a cursor to a chosen channel sample; other channel values follow that time. Locking does not make the selected channel the only channel allowed to pan or zoom.

## Properties, processing and reporting
Use **View → Properties** to inspect or edit name, unit, kind and limits. Unit metadata takes priority over name-based guesses. Tools offers channel appearance, playback, recorded phases, filters, formulas, engineering diagnostics, presets and optional extensions. Choose **Export Report** for PDF, Excel, CSV or PNG of the active analysis; additional SVG/HTML/Markdown exports are under Tools. **Save workspace** stores JSON and an adjacent NPZ: keep both together. **Restore** reopens the workspace.

## Changes in this version
Adds TDMS recordings with independent channel timing and engineering units, plus live mouse X/Y hover and nearest-sample inspection.

## Detailed readouts
The readout table shows A, B, Δ, minimum, maximum and average for visible channels. Choose full-recording or cursor-interval scope. Locked-channel values are pinned for easy access. Use **Add note** to annotate the plot and include notes in reports.

## Actuators
Recognized actuator commands show **0 = OFF, any other integer = ON**. Missing or fractional readings remain Unknown. Physical readings (for example heater watts) and program codes remain numeric. Override a channel under **Properties → Value interpretation**: Auto, Numeric/original or Actuator ON/OFF, then Apply. Raw values are retained. The readout shows ON time and duty percentage; unknown spans are excluded from known-time totals.

## Updates
Open **Info → Check for updates**. Read the release notes, choose **Download update**, then **Install update & restart**. Downloads are verified against the release SHA-256 checksum. Installation saves your current workspace in the local application data updates folder and restores it on restart. Wait for processing to finish first. The app folder must be writable; no administrator elevation is attempted. The previous executable is retained as ApplianceSignalStudio.previous.exe. If replacement or launch fails, the updater restores it and records install.log in the updates folder. A power interruption can require manually renaming the previous executable back. The portable app is updated using the standalone EXE; keep any remaining portable dependencies if you intend to use the backup. Your source recordings are never overwritten. Offline use and manuals continue to work without an internet connection. Future manuals are bundled with their matching app release.

## TDMS recordings
Open a `.tdms` file directly. The reader supports LabSys group/Value/dTime/Status recordings, channels sharing explicit time columns and NI waveforms with sampling increments. Each channel keeps its own timestamps and sample count. Time is displayed in minutes; channels without timing metadata use sample indices. Units, group metadata, quality status and original source readings are retained. Invalid LabSys quality is shown as unknown data. Already scaled engineering values are not scaled a second time; metadata formulas are never executed. Undeclared units remain unknown and can be edited in Properties. Known LabSys heater, pump and valve commands use ON/OFF interpretation; program and error codes remain numeric.

## Mouse X/Y hover
Move the mouse inside a plot for a live crosshair and compact readout. **Mouse X** shows the pointer coordinate in minutes (or the plot's own coordinate units); **Mouse Y** shows the pointer position in every displayed Y-axis scale. The nearest trace is highlighted with its actual sample timestamp, original physical value and unit. These are real samples, even when channels have different sampling rates. ON/OFF channels show states. A/B cursors and their locks stay unchanged. Moving outside the plot, hiding all channels or changing the plot ranges clears the transient readout. Hover guides are excluded from saved workspaces and report exports.

TDMS also works in recording alignment and bench comparison. Those workflows use a derived union of the recorded timestamps, carrying only earlier readings for at most five seconds (the synchronization engine’s existing tolerance). The direct Analysis view keeps the native channel clocks. Alignment retains the untouched TDMS source table separately from this synchronized projection.
