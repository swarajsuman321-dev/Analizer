# Studio 2.1.0 frontend

The default view remains two workspaces, native channel checkboxes, a multi-axis
plot, the cyan/amber cursor inspector and direct Export Report. Optional tools
restore earlier engineering, mapping, calibration, playback, navigation, presets,
plugin hooks and complete exports.

[FEATURE_PARITY.md](FEATURE_PARITY.md) maps every audited capability to its current
Qt location and records compatibility boundaries. [VALIDATION.md](VALIDATION.md)
records the validation evidence. Earlier Tk application copies remain excluded
from the build.
